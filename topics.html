SQL Injection Prevention

SQL Injection happens when attackers manipulate database queries using user input.

❌ Vulnerable Code


query = "SELECT * FROM users WHERE username = '" + user + "'";

✅ Secure Code


PreparedStatement stmt = conn.prepareStatement(
    "SELECT * FROM users WHERE username = ?"
);
stmt.setString(1, user);

Cross-Site Scripting (XSS)

XSS allows attackers to inject malicious scripts into webpages.

❌ Vulnerable Code


document.write(userInput);

✅ Secure Code


element.textContent = userInput;

Input Validation & Sanitization

Always validate user input before processing it.

❌ Vulnerable Code


let age = userInput;

✅ Secure Code


let age = parseInt(userInput);
if (!isNaN(age)) {
    console.log("Valid input");
}

Secure Password Hashing

Passwords should never be stored in plain text.

❌ Vulnerable Code


password = "123456";

✅ Secure Code


bcrypt.hash(password, 10);
